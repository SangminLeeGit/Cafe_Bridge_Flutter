LoadingState · EmptyState · NetworkState · AccessGate
상태사용 조건표현다음 동작근거
loading초기화, 세션 복원, 각 API 요청 중spinner + 화면별 로딩 문구자동 완료 대기LoadingState
cachestale/캐시 응답으로 화면을 채움캐시 시각을 포함한 안내새로고침 가능CacheNotice
emptyDB 미연결 또는 목록 데이터 없음제목 + 설명 + 새로고침새로고침EmptyState
networktransport error 또는 오프라인연결 불가 안내다시 시도NetworkState
locked현재 role이 minimumRole보다 낮음잠금 + 필요한 역할 배지조회는 유지, 실행은 차단AccessGate
task동기화·가격·배포 비동기 작업pending/running/result + 진행폴링, 취소 또는 재시도TaskPoller
