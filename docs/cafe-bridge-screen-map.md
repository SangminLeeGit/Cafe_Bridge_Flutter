# Cafe Bridge Android 화면 맵

`origin/design`의 화면 구성 의도를 현재 Flutter/Android 계약에 맞게 선별 적용한 기준선이다. API path, JSON 모델, 세션·캐시 정책은 기존 구현을 유지한다.

## 진입 구조

```text
AppRoot
├─ 초기화/세션 복원: 공통 준비 로딩
├─ 비인증: 로그인 / 실패 / 오프라인 안내 / 초기 설정 안내
└─ 인증 후 MainLayout
   ├─ 홈: 오늘 상태 → 일별 상세
   ├─ 인사이트: 개요 / 매출 흐름 / 메뉴 인사이트
   ├─ 업무: 상품 조회 / 원가 / 가격 반영 / 메뉴판 / 동기화 / 메뉴 작업대
   ├─ 인력: 대시보드 / 캘린더 / 근무 / 급여 / 직원
   └─ 더보기: 터치키 / 앱 설정 / 관리자 운영
```

## 권한과 화면 상태

| 영역 | 목적 | 최소 역할 | 주요 상태 |
| --- | --- | --- | --- |
| 홈 | 오늘 매출과 최근 영업일 확인 | viewer | 로딩, 빈 DB, 오류, 캐시, 네트워크 실패 |
| 인사이트 | 월간·기간·메뉴 분석 | viewer | 기간 선택, 로딩, 빈 데이터, 오류, 캐시 |
| 상품 조회 | 상품 검색·상세·가격 변경 진입 | viewer / 실행은 operator | 로딩, 검색 결과 없음, 오류, 재시도, 권한 |
| 원가 | 재료·레시피·원가율 조회 | operator | 로딩, 빈 목록, 오류, 재시도 |
| 가격 반영 | 가격 미리보기·영향 확인·실행 | operator | 입력 검증, 중복 실행, 진행, 성공, 실패·재시도 |
| 메뉴판 | 사이니지 초안 조회·제한 편집 | operator | 로딩, 미저장 변경, 검증 실패, 반영 결과 |
| 동기화 | 대상일 매출 수집·작업 추적 | operator | 대상일 확인, 중복 실행, 진행, 시간 초과, 재시도 |
| 메뉴 작업대 | 신규 메뉴·작업 이력 모니터 | admin | 로딩, 빈 목록, 권한, API 오류 |
| 인력 | 직원·시프트·급여 운영 | operator | 폼 검증, 빈 직원·근무, 미리보기, 저장 실패 |
| 터치키 | POS 표·배치 조회 | viewer | 로딩, 빈 구조, API 오류 |
| 앱 설정 | 서버·캐시·업데이트·세션 | viewer / 서버 변경은 admin 또는 debug | 연결 확인, 저장 확인, 로그아웃 확인 |
| 관리자 운영 | 배포·일일보고서·감사 상태 모니터 | admin | 빈 로그, 오류, 재시도, 권한 잠금 |

## 공통 Android 규칙

- 배경 `#F8FAFC`, 표면 `#FFFFFF`, 본문 `#0F172A`, 보조 텍스트 `#475569/#64748B`, 경계 `#E2E8F0`, 주요 액션 `#0D9488`을 `AppColors` 토큰으로 사용한다.
- 페이지 패딩 16dp, 카드 간격 12~16dp, 섹션 간격 20dp, 카드 radius 14dp, 조작 영역 최소 44dp를 기본값으로 사용한다.
- 청록은 선택·주요 실행·핵심 KPI에만 사용하고 성공·경고·오류는 색상과 텍스트를 함께 표시한다.
- 세 개 이상 입력 필드, 키보드, 검증 또는 저장이 필요한 흐름은 전면 화면 폼으로 유지한다.
- 고위험 실행은 `입력 → 검증 → 영향 요약 → 확인 → 백그라운드 작업 → 결과/재시도` 순서를 유지한다.
- 조회 화면의 캐시 상태와 시각을 표시하되 인사·급여·감사·인증 데이터는 디스크 캐시하지 않는다.
- 권한이 없는 기능은 탐색 구조에서 숨기지 않고 잠금 상태와 필요한 역할을 표시하며 `AccessGate`와 서버 권한으로 실행을 차단한다.
- 웹 전용 hover, 넓은 sidebar, 마우스 중심 drag 동작은 복제하지 않고 터치·safe area·시스템 뒤로 가기에 맞춰 구성한다.

## 보존한 웹 전용 범위

- 사용자 생성·권한 변경·비밀번호 초기화와 배포 실행
- 일일보고서 정책 변경·수동 재생성·재전송
- 신규상품 공식 import/export와 터치키 위치의 실제 EasyPOS 반영
- 원가 기준정보 저장과 사이니지 구조 변경
