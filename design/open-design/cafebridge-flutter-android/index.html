CAFE BRIDGE / MOBILE OPERATIONS

매출·메뉴·인력을 한 화면에서 운영합니다.

조회 전용 사용자부터 operator·admin 작업까지 실제 앱의 접근 조건을 보존합니다. 존재하지 않는 Drawer, BottomSheet, 신규 기능은 추가하지 않습니다.

ADB runtime basis
연결 기기 SM-G970N · 1080×2280 · 480dpi. 앱 콘텐츠 bounds는 2020px, Samsung system status/navigation 영역과 adjustResize 키보드 노출을 별도 반영했습니다. 표준 runtime permission popup은 없지만 APK 설치 시 Cafe Bridge의 '알 수 없는 앱 설치 허용' 설정 화면으로 이동하는 특수 권한 흐름이 있어 update completion frame에 반영했습니다.
Observed launch
로그인 전 상태에서 실제 로고, 운영 콘솔 로그인, 권장 업데이트 배너, 아이디/비밀번호, 로그인 상태 유지, 키보드, 빈 입력 검증을 확인했습니다.

읽는 순서

Foundation에서 토큰과 shell을 확인한 뒤 Main screens → Detail routes → Settings & admin → Dialogs & input → States로 흐릅니다. 동작 smoke flow는 기존 prototype/flows.html에 별도 보존했습니다.
